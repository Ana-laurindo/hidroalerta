
# HidroAlerta

Sistema para registro e acompanhamento de ocorrências relacionadas a alagamentos e chuvas intensas em Palmares - PE.

## Sobre o projeto

O HidroAlerta é um projeto acadêmico que busca organizar informações sobre ocorrências de alagamentos e situações relacionadas às chuvas em Palmares, Pernambuco.

A proposta é desenvolver uma plataforma para registrar, consultar e acompanhar ocorrências, reunindo informações sobre localização, data, horário, descrição e situação.

O projeto também tem como objetivo aplicar boas práticas de desenvolvimento de software, versionamento e gerenciamento de mudanças.

## Problema

Durante períodos de chuvas intensas, informações sobre ocorrências podem ficar espalhadas em diferentes canais, dificultando sua organização e consulta.

O HidroAlerta propõe centralizar esses registros em um espaço digital, facilitando a consulta e o acompanhamento das informações.

**Importante:** o sistema é uma proposta acadêmica e não substitui alertas oficiais, serviços de emergência ou órgãos responsáveis.

## Objetivo

Desenvolver uma solução digital que permita registrar, organizar, consultar e visualizar informações sobre ocorrências relacionadas a alagamentos em Palmares - PE.

## Funcionalidades previstas

- Cadastro de ocorrências.
- Registro de data e horário.
- Descrição da ocorrência.
- Classificação da situação.
- Pesquisa e filtros.
- Visualização das ocorrências em mapa.
- Histórico de registros.

## Tecnologias

- HTML5: estrutura das páginas.
- CSS3: estilos e responsividade.
- JavaScript: interações da interface.
- Git: controle de versão.
- GitHub: hospedagem do repositório e colaboração.

Backend e banco de dados poderão ser adicionados nas próximas etapas do desenvolvimento.

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Utilize o formulário para registrar ocorrências de teste.

Nesta versão inicial, os registros são armazenados localmente no navegador e não são compartilhados entre usuários.
