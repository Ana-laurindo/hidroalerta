HidroAlerta
Sistema para registro e acompanhamento de ocorrências relacionadas a
alagamentos e chuvas intensas em Palmares - PE.
Sobre o projeto
O HidroAlerta é um projeto desenvolvido para o contexto de Palmares-PE, com o
objetivo de organizar informações sobre ocorrências de alagamentos e situações
relacionadas às chuvas.
A proposta é criar uma plataforma onde seja possível registrar, consultar e
acompanhar ocorrências, reunindo informações como local, data, horário,
descrição e situação.
O projeto também será utilizado para aplicar conceitos de Git, GitHub,
versionamento e gerenciamento de mudanças.
Problema
Durante períodos de chuvas intensas, informações sobre ocorrências podem ficar
espalhadas em diferentes canais, dificultando sua organização e consulta.
O HidroAlerta busca solucionar esse problema criando um espaço para centralizar
os registros e facilitar o acompanhamento das informações.
O sistema é uma proposta acadêmica e não substitui canais oficiais de
emergência ou órgãos responsáveis.
Funcionalidades
● 📍 Cadastro de ocorrências;
● 📅 Registro de data e horário;
● 📝 Descrição da ocorrência;
● ⚠️ Classificação da situação;
● 🔎 Pesquisa e filtros;
● ️ Visualização das ocorrências em mapa;

● 📊 Histórico de registros.
Objetivo
Desenvolver uma solução digital que permita registrar, organizar e visualizar
informações sobre ocorrências relacionadas a alagamentos em Palmares-PE.
Tecnologias
● Git e GitHub — versionamento;
● HTML, CSS e JavaScript / React — interface;
● Node.js — backend;
● PostgreSQL/MySQL — banco de dados.
A stack poderá ser ajustada durante o desenvolvimento.
Versionamento
O projeto utilizará branches para organizar o desenvolvimento:
main
develop
feature/nome-da-funcionalidade
hotfix/nome-da-correcao
Exemplos de commits:
feat: adiciona cadastro de ocorrencias
fix: corrige formulario de cadastro
docs: atualiza README
test: adiciona testes de ocorrencias
As funcionalidades serão integradas por meio de Pull Requests e Code Review
antes do merge.
